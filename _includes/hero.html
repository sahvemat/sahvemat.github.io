{% comment %} A post explicitly reserved for another homepage slot (currently just type: analysis, used by analysis.html) must never double up as a fallback here — otherwise the same post can end up shown in two places on the homepage at once. GitHub Pages builds with Jekyll 3.10's where_exp, whose parse_condition only accepts a single left/operator/right comparison — no and/or chaining (unlike newer Jekyll). Every where_exp below must stay a single condition; multi-condition filtering is done by piping through where_exp more than once instead.
